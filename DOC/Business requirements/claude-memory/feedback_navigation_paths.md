Always provide the full navigation path when mentioning any page or feature in the app.

**Why:** The user cannot find pages without knowing where they sit in the sidebar. Saying "go to /master-data/projects" is not enough — always say "Organization → Projects (`/master-data/projects`)".

**How to apply:** Any time a page, screen, or feature is referenced in a response, include the full sidebar path first (e.g. "Organization → Projects"), then the URL in parentheses if helpful.

Section 1
Module Overview & Preconditions
Every position change in AVANIIS HR uses the effective-date pattern — old records are closed, new records are opened. Nothing is deleted. Every action produces an immutable audit entry.
✅ Preconditions Checklist — All must be true before initiating any transfer
✓
Employee has ACTIVE assignment
Configure at: /persons/[id] → Assignments
✓
Target position exists and is not frozen
Configure at: /master-data/positions
✓
Target department exists under correct legal entity
Configure at: /master-data/departments
✓
Target grade has a defined salary band
Configure at: /master-data/grades
✓
Approval workflow is configured
Configure at: /settings/workflows
✓
For cross-entity: target legal entity exists
Configure at: /master-data/legal-entities
✓
For promotion: Finance approver role is assigned
Configure at: /users → role = FINANCE
🚫 Blocking Conditions — System will refuse to proceed
PENDING_HIRE statusCannot initiate transfer — employee not yet active. Activate the assignment first at /persons/[id] → Assignments.
is_frozen = trueTarget position is frozen (budget hold). Unfreeze at Master Data → Positions, or choose a different position.
Payroll LOCKEDA payroll run is in LOCKED or APPROVAL_PENDING status. Finance approval step is frozen until payroll closes.
Employee on ACTIVE leaveEffective date must be set to on or after the employee's expected return date.
Grade rank not higher (Promotion)For promotions, new_grade rank must strictly exceed current grade rank. Equal or lower grade = system block.

Approval Inbox Guide
Two paths to the same decision. Every approval also enforces BR-29 — three buttons, always: Approve · Reject · Delegate.
Path A — In-App
① Open Approvals in sidebar — badge shows count
② Find the request — sort by SLA Remaining to prioritise
③ Click the row — review full details in the expanded panel
④ Click Approve / Reject / Delegate — decision recorded immediately
Path B — Email One-Click
① Receive email notification with request summary
② Click the Approve / Reject / Delegate link in the email
③ Browser opens a confirmation page — no login required
④ Decision recorded. JWT token consumed (single-use, expires 7 days)
ℹ Tokens are single-use. If the link says "already actioned", check the in-app inbox for current status.

Section 8
Operational Scenarios
Four real-world cases. Each shows the exact resolution path, the rule reference, and the compliance risk if steps are missed.
A
Employee transferred mid-payroll month
1
HR sets effective_date = 15th of current month
2
System detects open payroll run for this period (status DRAFT or CALCULATED)
3
Payroll auto-splits: old cost centre days 1–14 · new cost centre days 15–month end
4
GL journals posted to both entities for respective day ranges
5
HR verifies split at Payroll → Runs → [current run] → review entries
6
Payroll run proceeds normally — no manual adjustment needed
⚠ If payroll is already LOCKED, the effective date must move to the next month. The system enforces this — the submit button is blocked with an explanation.
BR-TR-001 · effective_date pattern · pro-rata cost allocation
B
Manager on leave — urgent acting assignment
1
HR Admin: Org Chart → click ··· on manager's card → Assign Acting Manager
2
Search and select the acting person from the drawer
3
Set start = today · end = manager's expected return date
4
System triggers acting approval — HR Director (expedited, 4-hour SLA for urgent)
5
On approval: amber strip shows on org chart · is_acting = true recorded
6
Set delegation at Settings → Delegations so acting person receives approval notifications
⚠ If acting will exceed 6 months — UAE Labour Law requires a substantive promotion. ARIA will alert HR Admin 5 days before the 6-month limit.
BR-AC-001 · is_acting = true · acting_end_date required
C
Promotion rejected by Finance — what to do
1
Finance rejects with mandatory reason (min 10 chars)
2
Status → REJECTED (terminal — this workflow instance cannot be reopened)
3
HR Admin reviews rejection reason at /approvals → Completed Requests
4
Three options: (a) Revise salary to fit the band — create a NEW request. (b) Request a grade-band exception — escalate to HR Director. (c) Cancel the promotion entirely.
5
New submission creates a new workflow_instance — audit trail from both requests preserved
⚠ Do not attempt to reopen a REJECTED workflow — the system does not support workflow reopen. Always create a new request.
BR-29 · REJECTED is terminal · create new request to retry
D
Cross-entity transfer — EOSB must be settled
1
HR initiates cross-entity transfer — 4-level approval chain (Manager → HR Dir → Finance → Legal)
2
System calculates EOSB from hire_date to effective_date using employee's nationality scheme
3
HR presents EOSB amount to employee — two options: (a) Pay out before transfer. (b) Carry forward with written inter-entity agreement.
4
Decision is documented and attached to the transfer record as a mandatory attachment
5
New contract created under target legal entity — service start date resets
6
Payroll switches to new entity's structure from effective date
⚠ UAE Labour Law (FDL 33/2021): EOSB documentation must be completed BEFORE the transfer executes. Missing documentation is a compliance violation.
BR-CE-001 · BR-EOSB-001 · FDL 33/2021
Section 9
Troubleshooting Knowledge Base
Every problem has three layers: what the user sees, what caused it, and exactly how to fix it.
🚫 Request Won't Submit
Submit button is greyed out
One or more required fields are empty, or assignment_status ≠ ACTIVE
→ Check all fields marked *. Verify assignment status at /persons/[id] → Assignments tab.
"Target position is frozen" error
is_frozen = true on the selected position
→ Choose a different position OR unfreeze at Master Data → Positions (requires HR Director approval).
"Effective date is in the past"
Backdated transfers > 30 days require a dual-approval workflow (BR-WF-010)
→ Use a future date OR accept the dual-approval flow that triggers for past dates > 30 days.
⏳ Approval Is Stuck
Request pending 48+ hours with no action
SLA has been breached
→ System auto-escalates. HR Admin can also manually escalate from /approvals → find request → Escalate.
Approver is on leave with no delegate set
No delegation rule configured for this approver
→ HR Admin: Settings → Delegations → Add Rule. Or manually reassign from /workflows/[instanceId].
Finance step frozen / not moving
Payroll run is in LOCKED or APPROVAL_PENDING status
→ Wait for payroll to close (1–2 business days). Finance approver is auto-notified when the lock clears.
🔍 Employee Missing from Org Chart
New hire not visible on org chart
assignment_status = PENDING_HIRE — not yet ACTIVE
→ /persons/[id] → Assignments → confirm assignment → set to ACTIVE.
Employee visible in wrong department
Transfer was approved but effective_date is in the future
→ Expected behaviour. Org chart reflects current effective assignment. Node moves automatically on effective_date.
Employee not visible after a filter change
A department or status filter is hiding the node
→ Click "Clear Filters" in the filter panel (⚙️ icon in org chart top bar).
⟲ Acting Assignment Issues
Amber strip not showing on org chart
Acting assignment is PENDING_APPROVAL — not yet ACTIVE
→ Check /approvals. Approve the acting assignment. Amber strip appears immediately — no page refresh needed.
Acting person not receiving team's approval notifications
Delegation was not set up alongside the acting assignment
→ Settings → Delegations → Add Rule — set original manager as delegator, acting person as delegate, matching dates.
ARIA alerts "acting approaching 6-month limit"
is_acting = true AND acting_end_date is within 5 days of the 6-month mark
→ Initiate a promotion workflow immediately OR formally extend with HR Director sign-off. Do not simply update acting_end_date — that bypasses UAE Labour Law (BR-AC-001 · BR-AC-002).
Section 10
ARIA Intelligence Notes
Eight documented ARIA queries — each showing the dependency-check sequence and response logic. This is ARIA's reasoning layer for the Transfers & Promotions module.
ARIA
Adaptive Resource Intelligence Agent — Transfer & Promotion Dependency Logic
Access from /aria or from the org chart chat panel (🤖 button, HR Admin and above only)
"Why hasn't Ahmed's transfer been processed?"
ARIA checks in order
1.Does a transfer_request exist for Ahmed where status ≠ DRAFT?
2.Query workflow_instances WHERE resource_id = transfer_request.id
3.Find approval_steps WHERE status = PENDING → identify current approver
4.Compare created_at + SLA_hours vs current timestamp → breach check
"Ahmed's transfer is at Step 2 — pending approval from [approver]. Waiting 26 hours against a 48-hour SLA. No breach yet. If no action by [timestamp], it auto-escalates to HR Director."
workflow_instances · approval_steps · SLA timer
"Is Sara eligible for promotion to Grade 7?"
ARIA checks in order
1.Sara's current grade_id → grades.rank
2.Grade 7 rank > Sara's current grade rank? (must be true)
3.Sara's current salary vs grade_salary_ranges for Grade 7 (min/max)
4.Open disciplinary records? → blocks promotion if yes
5.Is a Finance approver assigned to any user? → stalls workflow if not
"Sara is eligible for Grade 7 promotion. Her Grade 5 salary of AED X falls within the G7 band (AED Y–Z). No open disciplinary records. Finance approver is assigned. You may proceed."
BR-PR-001 · grades · grade_salary_ranges · worker_assignments
"What happens to EOSB if I transfer Ahmed to Avaniis Construction?"
ARIA checks in order
1.Is target entity different from Ahmed's current legal_entity_id? → YES = cross-entity
2.Apply BR-CE-001: cross-entity transfer requires EOSB settlement
3.Calculate EOSB from persons.hire_date to proposed effective_date using nationality_category
4.Check jurisdiction: TRADITIONAL scheme vs DEWS vs VSS
"This is a cross-entity transfer. Ahmed's EOSB of approximately AED [calculated] must be settled or formally carried forward before the transfer executes. This is a UAE Labour Law requirement (FDL 33/2021)."
BR-CE-001 · BR-EOSB-001 · FDL 33/2021 · persons.hire_date
"Show me all acting assignments expiring this month"
ARIA checks in order
1.worker_assignments WHERE is_acting = true AND acting_end_date BETWEEN today AND last_day_of_month
2.For each: calculate days from assignment start to acting_end_date
3.Flag any where total duration exceeds 150 days (approaching 6-month UAE Law limit)
Returns structured list: employee, position, start date, end date, days remaining. Acting assignments over 5 months are flagged in amber with a promotion workflow recommendation.
BR-AC-001 · worker_assignments.is_acting · acting_end_date
"Why is the transfer form blocked for me?"
ARIA checks in order
1.What is the user's role? EMPLOYEE = no transfer initiation rights (ESS only)
2.If HR_ADMIN: is employee's assignment_status = ACTIVE?
3.Is target position is_frozen = true?
4.Is payroll_runs.status = LOCKED or APPROVAL_PENDING for this entity?
ARIA diagnoses the specific blocker and links directly to the resolution. Example: "The target position [name] is frozen. Unfreeze it at Master Data → Positions, or choose a different position."
Role permissions · worker_assignments · positions.is_frozen · payroll_runs.status
"Who is covering for the Finance Manager while she's on leave?"
ARIA checks in order
1.Find Finance Manager's position_id from worker_assignments WHERE assignment_status = ON_LEAVE
2.Query worker_assignments WHERE is_acting = true AND position_id matches AND effective_start_date <= today AND (acting_end_date IS NULL OR acting_end_date >= today)
"[Acting person name] is covering as Acting Finance Manager from [start] to [acting_end_date]. [X] days remaining."
worker_assignments.is_acting · acting_end_date · position_id
"I approved a transfer by email 2 days ago but nothing changed"
ARIA checks in order
1.Find the workflow instance for this transfer
2.Was the email JWT token consumed? (single-use — check token log)
3.Is this a multi-step workflow? Is there a next step now pending?
4.Has the effective_date been reached yet? (system applies ON the date, not on approval)
"Your approval was recorded on [date]. The request is now at Step 3 — pending Finance approval. The org chart will update on [effective_date], not today."
workflow_instances · JWT token · effective_date pattern
"Can I undo an approved transfer?"
ARIA checks in order
1.What is the current transfer status?
2.If APPROVED and effective_date is in the future → RECALL is possible (HR Admin or HR Director only)
3.If EXECUTED (effective_date passed) → cannot undo; new transfer request required to reverse
"If the effective date has not passed, the transfer can be recalled from /approvals. If it has already taken effect, create a new transfer request to reverse it. All changes are in the audit log."
effective_date pattern · RECALLED status · audit_log (BR-AUDIT-001)

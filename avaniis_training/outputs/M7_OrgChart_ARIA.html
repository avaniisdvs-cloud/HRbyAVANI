Section 1
Module Overview & Preconditions
The Org Chart renders the live Avaniis / AVANIIS Real Estate employee hierarchy from worker_assignments using a recursive CTE in PostgreSQL. ARIA (Adaptive Resource Intelligence Agent) answers natural-language HR queries by detecting intent, executing targeted DB queries, masking PII fields, and returning bilingual structured responses. HR Admins can initiate acting assignments, transfers, and hiring requests directly from org chart node menus. All other roles have read-only access.

4
Click the highlighted node — canvas auto-pans and zooms to centre on Mohammed

Alternatively: ask ARIA "Find Mohammed Al-Dhaheri" → ARIA offers "Pan to Node" action button

B
Acting end date wrong — update before 6-month breach
1
ARIA alert arrives: "Fatima Al Zaabi's acting assignment ends 2026-07-01 — 5 days from the 6-month UAE Law limit (BR-AC-001)"
2
HR Admin navigates to /org-chart → finds Fatima's amber-strip node → clicks ···
3
Choose "Edit Acting Assignment" from context menu — drawer opens pre-filled
4
Two options: (a) Update acting_end_date to earlier date — submits acting extension request. (b) Convert to permanent promotion — initiates promotion workflow (BR-PR-001)
5
Promotion workflow triggers 4-step chain: Manager → HR Admin → HR Director → Finance
6
On promotion approval: is_acting = false, amber strip removed, new grade and title applied from effective_date
⚠ Simply extending acting_end_date beyond 6 months bypasses UAE Labour Law (BR-AC-001). The system flags this as a compliance risk and requires HR Director sign-off for any extension past 6 months.
BR-AC-001 · BR-AC-002 · acting_end_date · is_acting · FDL 33/2021
C
ARIA wrong answer — confidence fallback and escalation
1
HR Admin asks: "What is the total bonus budget for Q3 2026 across all departments?"
2
ARIA evaluates the query — intent detected as COMPLIANCE but confidence score = 0.58 (below 0.7 threshold)
3
ARIA enters ESCALATION_OFFERED state — responds: "I'm not confident enough to calculate this accurately. This query requires data from the Finance ERP system which I do not have direct access to."
4
ARIA offers: "Would you like me to route this query to the Finance team? Or navigate to Reports → Payroll Analytics for the closest available data?"
5
HR Admin clicks "Navigate to Payroll Analytics" — redirected to /reports/payroll
6
Interaction is logged to audit_log regardless of fallback — action = ARIA_ESCALATION
⚠ Never override ARIA's confidence fallback by re-asking in a different way hoping to get a higher score. The 0.7 threshold exists to prevent incorrect data being acted on as authoritative.
CONFIDENCE_CHECKED · threshold 0.7 · ESCALATION_OFFERED · audit_log
D
Org chart not reflecting approved transfer — effective date in future
1
HR Admin approves Omar Al-Rashidi's transfer from IT to Operations on 2026-05-20 — effective_date = 2026-06-01
2
HR Admin checks org chart on 2026-05-22 — Omar still shows under IT department
3
This is expected behaviour. Org chart renders the current effective assignment, not the approved future assignment
4
To verify the transfer was approved: /approvals → Completed Requests → find Omar's transfer (status = APPROVED)
5
On 2026-06-01 at midnight UAE time, the system cron job applies the effective_date change — Omar's node moves to Operations automatically
6

Section 9
Troubleshooting Knowledge Base
Four common issue categories. Every problem has three layers: what the user sees, what caused it, and the exact fix path with field references.
🔍 Employee Missing from Org Chart
New hire not visible on any org chart view
worker_assignments.assignment_status = PENDING_HIRE — not yet confirmed as ACTIVE
→ /persons/[id] → Assignments tab → confirm hire → set status = ACTIVE. Node appears immediately on next chart load.
Employee visible in another user's filter but not mine
An active department or status filter is hiding the node from your view
→ Click ⚙️ icon in org chart toolbar → "Clear Filters". Or ask ARIA "Show all employees" to reset to Full Org view.
Employee exists in /persons but never appears on org chart
positions.is_confidential = true — hidden from your role level
→ Requires HR_ADMIN minimum. Check /master-data/positions → [position] → is_confidential field. SUPER_ADMIN can toggle visibility.
⟲ Acting Amber Strip Not Showing
Assigned acting role — amber strip still not visible on node
Acting assignment is in PENDING_APPROVAL — is_acting = true is only set on final approval
→ Check /approvals. Find the acting assignment request. Approve it — amber strip appears immediately, no page refresh needed.
Amber strip disappears unexpectedly
acting_end_date has been reached — system automatically sets is_acting = false
→ Expected behaviour. If acting is still needed, initiate a new acting assignment via ··· menu. Do not manually edit the database record.
Acting person not receiving the manager's approval notifications
Delegation rule was not set up — acting assignment ≠ workflow delegation
→ /settings/delegations → Add Rule. Delegator = original manager, Delegate = acting person, date range matching acting period. These are separate steps.
🤖 ARIA Not Responding
ARIA panel shows "AI assistant unavailable"
ANTHROPIC_API_KEY is missing or invalid in environment variables
→ SUPER_ADMIN: check /settings/configuration → AI Settings → verify ANTHROPIC_API_KEY is set. Request a new key from Anthropic console if needed.
ARIA responds with "Rate limit reached, please try again in a moment"
Anthropic API rate limit hit — RateLimitError is caught and returns bilingual AriaResponse
→ Wait 30–60 seconds and retry. If persistent, check the Anthropic usage dashboard for the API key. Consider upgrading the API tier for high-volume usage.
ARIA answers but gives a different answer for the same question
ARIA queries live database data — if assignments or positions changed, the answer correctly reflects the new state
→ This is expected. ARIA is not cached — every query hits the current database. If answers seem inconsistent, check /persons for recent assignment changes.
⬇ PDF Export Blank Pages
PDF export produces blank or cut-off pages
Too many nodes (>200) overflow the A3 landscape canvas used by jsPDF 4.2.1
→ Apply a department filter first to reduce visible nodes to ≤200. Then export. The export captures the current filtered view, not the full org.
PNG export produces a blank white image
html-to-image library timed out before rendering completed — happens with 150+ nodes
→ Filter to a single department or team. Wait 3 seconds after the chart fully loads before clicking Export. Avoid exporting immediately after a filter change.
Export missing some nodes that are visible on screen
Nodes outside the current viewport are not in the DOM snapshot used by html-to-image
→ Use Ctrl+Shift+F to "Fit All" before exporting — this ensures all filtered nodes are in the render viewport. Then export.

ARIA Intelligence Notes
Eight documented ARIA queries for the Org Chart module — each shows the dependency-check sequence, exact table and field references, and what ARIA actually says in response.
ARIA
Adaptive Resource Intelligence Agent — Org Chart & Analytics Query Logic
Access from /aria (HR Admin+) · /me/aria (Employee ESS only) · Org chart 🤖 panel button
"Show me the Finance department org chart"
ARIA checks in order
1.Intent = ORG_QUERY · sub-intent = PAN_TO_NODE · target = Finance dept
2.Query departments WHERE name_en ILIKE '%Finance%' → get department_id
3.Verify at least one ACTIVE worker_assignment in this department exists
4.Confidence ≥ 0.7 → proceed · Return dept subtree + action button
"Found Finance Department — 44 employees, 1 acting assignment, 3 vacant positions. The department head is Sara Al Hammadi (Acting Finance Director). Clicking below will open the org chart filtered to Finance."
[Show Finance Department →]
departments.name_en · worker_assignments · PAN_TO_NODE intent · vacancy_start_date
"Who reports directly to the CEO?"
ARIA checks in order
1.Intent = ORG_QUERY · sub-intent = DIRECT_REPORTS
2.Locate CEO position: positions WHERE title_en ILIKE '%Chief Executive%' → position_id
3.worker_assignments WHERE line_manager_id = CEO.person_id AND assignment_status = ACTIVE
4.Mask PII: show name_en, title_en, department only — no emirates_id, no IBAN
"Khalid Al Mansouri (CEO) has 6 direct reports: Sara Al Hammadi (Acting Finance Director), Omar Hassan (Head of IT), Fatima Al Zaabi (Head of Legal), Ahmed Al-Rashidi (Operations Manager), Mohammed Hassan (Head of HR), and Rania Al-Sayed (Sales Director)."
worker_assignments.line_manager_id · positions.title_en · DIRECT_REPORTS intent
"Find Ahmed Al-Rashidi in the org chart"
ARIA checks in order
1.Intent = ORG_QUERY · sub-intent = PERSON_SEARCH
2.persons WHERE name_en ILIKE '%Ahmed Al-Rashidi%' → get person_id and current assignment
3.worker_assignments WHERE person_id = match AND assignment_status = ACTIVE → get position, dept, manager
4.Return structured card + "Pan to Node in Org Chart" action button
"Ahmed Khalid Al-Rashidi — Senior Financial Analyst, Finance Department, Grade G6. Reports to Sara Al Hammadi. ACTIVE since 12 Feb 2024. [Pan to Node in Org Chart] button offered."
persons.name_en · worker_assignments.position_id · PERSON_SEARCH intent · PAN_TO_NODE action
"How many vacancies are there in the IT department?"
ARIA checks in order
1.Intent = DIAGNOSTIC · sub-intent = VACANCY_COUNT
2.departments WHERE name_en ILIKE '%IT%' OR name_en ILIKE '%Information Technology%' → department_id
3.positions WHERE department_id = IT AND vacancy_start_date IS NOT NULL → count + dates
4.Calculate days open for each vacancy from vacancy_start_date to today
"IT Department has 4 vacant positions: Systems Architect (open 51 days), Data Engineer (open 38 days), IT Support Lead (open 22 days), and Network Administrator (open 14 days). Average days open: 31. Consider raising hiring requests for the 2 positions open beyond 30 days."
positions.vacancy_start_date IS NOT NULL · department_id · VACANCY_COUNT intent
"Show acting assignments expiring this month"
ARIA checks in order
1.Intent = HR_ACTION · sub-intent = ACTING_EXPIRY_REPORT
2.worker_assignments WHERE is_acting = true AND acting_end_date BETWEEN today AND last_day_of_month(today)
3.For each: calculate duration from effective_start_date to acting_end_date in days
4.Flag any where total duration ≥ 150 days (approaching 6-month UAE Law limit BR-AC-001)
"3 acting assignments expire in May 2026: (1) Sara Al Hammadi — Acting Finance Director, ends 31 May 2026, 148 days total [⚠ APPROACHING 6-MONTH LIMIT]. (2) Mohammed Hassan — Acting IT Manager, ends 20 May 2026, 62 days. (3) Fatima Al Zaabi — Acting Ops Lead, ends 25 May 2026, 44 days."
worker_assignments.is_acting · acting_end_date · BR-AC-001 · 6-month limit flag
"What is the current Emiratisation percentage?"
ARIA checks in order
1.Intent = COMPLIANCE · sub-intent = EMIRATISATION_METRIC
2.COUNT all ACTIVE worker_assignments → total headcount denominator
3.COUNT persons WHERE nationality_category = 'UAE_NATIONAL' AND assignment_status = ACTIVE
4.Return percentage + flag if below UAE Federal target (varies by sector)
"Current Emiratisation: 42.3% (104 UAE Nationals out of 247 ACTIVE employees). This includes contractors. For the official Ministry of HR metric, filter to PERMANENT employees only: 45.1% (98/217). Both figures exceed the sector target of 40%. ✓"
persons.nationality_category · worker_assignments.assignment_status · EMIRATISATION_METRIC intent
"Who has the most direct reports in the company?"
ARIA checks in order
1.Intent = ORG_QUERY · sub-intent = SPAN_OF_CONTROL_RANK
2.SELECT line_manager_id, COUNT(*) FROM worker_assignments WHERE assignment_status = ACTIVE GROUP BY line_manager_id ORDER BY COUNT DESC LIMIT 5
3.JOIN persons ON line_manager_id = person_id to get manager names
4.Flag managers with > 8 reports as overloaded (org-chart orange ring indicator)
"Top 5 by direct reports: (1) Omar Hassan, Head of IT — 9 reports [⚠ Overloaded]. (2) Sara Al Hammadi, Acting Finance Dir — 7 reports. (3) Mohammed Hassan, Head of HR — 6 reports. (4) Fatima Al Zaabi, Head of Legal — 5 reports. (5) Khalid Al Mansouri, CEO — 6 reports. Average span: 4.2."

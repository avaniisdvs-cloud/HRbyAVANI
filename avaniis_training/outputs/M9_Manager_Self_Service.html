Section 1
Module Overview & Preconditions
Manager Self-Service (MSS) gives line managers a dedicated workspace to manage their direct reports — reviewing leave, approving timesheets, viewing team org charts, delegating approvals, and accessing ARIA team analytics. All MSS routes are at /manager/* and require an ACTIVE worker assignment with the MANAGER role.
✅ Preconditions for MSS Access
✓
User has MANAGER role assigned
Configure: /users → Role = MANAGER
✓
At least one direct report assigned
Configure: /persons/[id] → line_manager_id
✓
Microsoft Entra ID SSO active
Configure: /users → SSO tab
✓
Leave module configured (M2)
Required for leave approval at /approvals
✓
Timesheet rules configured
Configure: /master-data/timesheet-rules
✓
Approvals workflow active (M5)
Required for BR-29 three-button approvals
✓
ARIA enabled with manager scope
Configure: /settings/aria → Manager scope ON
🚫 Blocking Conditions
No direct reports assignedMSS dashboard empty — no one to manage. Assign line_manager_id on worker assignments.
EMPLOYEE role onlyManager role must be assigned separately — EMPLOYEE role does not unlock MSS views.
Delegation expiredIf delegatee's assignment ends, pending delegated approvals return to original manager.
48h SLA breachLeave and timesheet approvals exceeding SLA trigger HR Admin escalation notification.

Operational Scenarios
Four real-world MSS situations with step-by-step resolution.
A
Manager cannot see approval items
1
Manager opens /approvals — shows "No items pending"
2
Check: does the manager have any employees with line_manager_id pointing to them?
3
If no direct reports, no approvals will ever appear — assign line_manager_id on worker assignments
4
If direct reports exist: check that their leave request is SUBMITTED (not DRAFT)
5
If status = DRAFT, employee has not submitted yet — only they can do that
worker_assignments.line_manager_id · absence_requests.status
B
48-hour SLA breach — HR notified
1
HR Admin receives alert: "Manager [name] has 2 approval items overdue by 48h"
2
HR Admin: /approvals → filter by manager → find overdue items
3
HR Admin can either: (a) escalate to manager with reminder, or (b) approve on behalf if manager is unavailable
4
HR Admin override is logged in audit_log with reason field required
⚠ Repeated SLA breaches trigger escalation to HR Director. Configure SLA in /settings/workflows → SLA tab.
workflow_instances · SLA · audit_log · HR override
C
Manager wants to bulk-delegate before annual leave
1
Manager about to go on leave and has 5 pending approval items
2
/approvals → ⋯ menu → Delegate All Pending
3
Search for another manager — must have MANAGER role and ACTIVE assignment
4
Select delegatee — all 5 items move to their inbox immediately
5
Original manager receives notification for each item when acted on
BR-29 delegation · MANAGER role enforced · bulk delegate
D
Employee says they cannot see their leave request status
1
Employee submits leave — status shows SUBMITTED, then disappears from /me/leave
2
This is a refresh issue — tell employee to reload /me/leave
3

If found in DB but not shown — check if it was accidentally RECALLED by HR Admin

Section 9
Troubleshooting
Common MSS issues — problem, root cause, and exact resolution.
🚫 Cannot Access /approvals
Approvals tab not showing in sidebar
User has EMPLOYEE role only — MANAGER role not assigned
→ SUPER_ADMIN: /users → find user → Role field → assign MANAGER role. Sidebar updates on next login.
Approvals shows but always empty
No direct reports with line_manager_id pointing to this manager
→ HR Admin: /persons → find each direct report → Assignments → set line_manager_id to this manager.
Can see approvals but cannot approve
Workflow module not configured (M5 prerequisite)
→ Check /settings/workflows. At least one approval workflow must be active for approvals to function.
⏳ Approval Issues
Only 2 buttons showing instead of 3
UI customization removed Delegate — this violates BR-29
→ SUPER_ADMIN: /settings/workflows → Approval Settings → ensure "Show Delegate" is ON. This is a mandatory requirement.
Delegated item returned to original manager
Delegatee's assignment became SUSPENDED/TERMINATED
→ Check delegatee's assignment_status. Reassign to another active manager.
Cannot delegate — person not in list
Target person has EMPLOYEE role only, not MANAGER
→ Assign MANAGER role at /users for the target person. They then appear in the delegation search.
👥 Team View Issues
Team member missing from /manager/team
worker_assignments.line_manager_id not set correctly
→ HR Admin: /persons/[employee_id] → current assignment → set line_manager_id to this manager's person ID.
Cannot see salary in team view
By design — managers cannot see salary data
→ Expected behaviour. Salary data is HR Admin scope only. Contact HR Admin for salary-related decisions.
Leave calendar shows wrong data
Approved leave not showing — may be a different entity
→ Check that the employee and manager are in the same legal_entity_id. Cross-entity visibility is restricted.
🤖 ARIA Team Issues
ARIA showing data for wrong team
ARIA at /manager/aria should auto-scope to requesting manager's direct reports
→ Check worker_assignments.line_manager_id for all shown employees. If wrong, reassign at /persons.
ARIA refuses to answer about a colleague's team
Correct behaviour — cross-team queries blocked at governance layer
→ Expected. Ask HR Admin or use /reports for cross-team analytics.
ARIA not showing pending approvals count
Approvals data source not enabled in ARIA Behaviour tab
→ SUPER_ADMIN: Settings → AI & Access → ARIA Behaviour → enable Approvals data source.
Section 10
ARIA Intelligence — Manager Team Queries
What managers can ask ARIA about their team. Scoped to direct reports only — cross-team queries are blocked.
ARIAManager Self-Service — Team Query Reference
"Who on my team is on leave this week?"
ARIA checks in order
1.Get requesting manager's person_id from session
2.worker_assignments WHERE line_manager_id = manager → get direct_report_ids
3.absence_requests WHERE person_id IN direct_reports AND status=ACTIVE AND date range = this week
"Sara Al-Zaabi is on annual leave this week (until 26 May). No other direct reports have approved leave this week."
worker_assignments · absence_requests · manager scope
"How many pending approvals do I have?"
ARIA checks in order
1.workflow_instances WHERE assigned_to = manager AND status = PENDING_REVIEW
2.Check each item's created_at against 48h SLA threshold
3.Flag urgent items near SLA breach
"You have 3 pending approvals: 2 leave requests and 1 timesheet. ⚠ Sara's timesheet has been pending 48 hours — SLA threshold reached. Review it at /approvals now."
workflow_instances · SLA 48h · /approvals
"What is Ahmed's current leave balance?"
ARIA checks in order
1.Confirm Ahmed is a direct report of requesting manager
2.absence_balances WHERE person_id = Ahmed AND leave_type = ANNUAL
"Ahmed has 14 days of annual leave remaining. His request for 16–20 June would leave him with 9 days. He has sufficient balance."
absence_balances · direct report scope · manager only
"Show me all team members currently active"
ARIA checks in order
1.worker_assignments WHERE line_manager_id = manager → all direct reports
2.Filter by assignment_status = ACTIVE (not ON_LEAVE, SUSPENDED)
"Your team has 4 members. Currently ACTIVE: Ahmed Al-Mansoori, Mohammed Al-Rashidi, Fatima Al-Suwaidi. ON_LEAVE: Sara Al-Zaabi (returns 27 May)."
worker_assignments · assignment_status · direct report scope
"How many days leave has my team taken this year?"
ARIA checks in order
1.absence_requests WHERE person_id IN direct_reports AND status=COMPLETED AND year=2026
2.Sum total_days by person
"Year-to-date leave by team member: Ahmed 16d · Sara 21d · Mohammed 8d · Fatima 12d. Team average: 14.25 days of the 30-day annual entitlement."
absence_requests · direct report scope · year filter
"Can you tell me what salary Ahmed is on?"
ARIA checks in order
1.Requesting user role = MANAGER
2.Salary data → HR_ADMIN scope only → ACCESS DENIED
"Salary data is restricted to HR Admin and above. I'm not able to share this with you at the MANAGER scope. Please contact your HR Admin for compensation queries."
Role scope enforcement · salary = HR_ADMIN only
"I want to know about the team lead Sara's workload"
ARIA checks in order
1.Confirm Sara is a direct report of requesting manager
2.Check timesheets, leave, pending items for Sara
"Sara is currently on leave (returns 27 May). Before leave, she submitted 42.5 hours timesheet for the last week — that is pending your approval. 3 leave requests approved this year (21 days total)."
timesheets · absence_requests · direct report scope
"What is the team headcount?"
ARIA checks in order
1.worker_assignments WHERE line_manager_id = manager → count
2.Break down by assignment_status
"Your team headcount is 4 direct reports: 3 ACTIVE, 1 ON_LEAVE. No PENDING_HIRE or SUSPENDED members currently."
worker_assignments.line_manager_id · status breakdown

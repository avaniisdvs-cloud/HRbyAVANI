Section 1
Module Overview & Preconditions
The Reporting & Analytics module at /reports gives HR Admins and Super Admins access to real-time workforce analytics, custom report builders, scheduled export jobs, and ARIA-powered natural language insights. All reports are role-scoped — managers only see their team data, HR Admins see all.
✅ Preconditions for Reporting
✓
HR Admin or Super Admin role
Full reports at /reports require HR_ADMIN minimum
✓
At least one active employee in system
Required for any headcount or leave report
✓
Payroll module live for payroll reports (M3)
Required at /reports → Payroll
✓
Leave rules configured (M2)
Required for leave utilisation reports
✓
SMTP configured for scheduled reports
Configure: /settings/notifications
✓
ARIA enabled for natural language queries
Configure: /settings/aria → Active ON
✓
Oracle ERP sync active (for payroll GL reports)
Configure: /settings/integrations → Oracle ERP
🚫 Blocking Conditions
EMPLOYEE role/reports is fully blocked — employees cannot access any reports. Redirect to /me/payslips for personal data.
No data existsReport builder will return empty results if no records match the filter criteria. This is not an error.
Cross-entity filterManagers can only filter by their own legal_entity_id. Cross-entity reports require HR_ADMIN or SA.
Scheduled export failsSMTP misconfiguration silently drops scheduled report emails — always test delivery after setup.

Section 9
Troubleshooting
Common reporting issues — cause and exact resolution.
🚫 Reports Not Loading
/reports shows "Access denied"
User has EMPLOYEE or MANAGER role — only HR_ADMIN and SA can access /reports
→ SUPER_ADMIN: /users → find user → assign HR_ADMIN role. Managers can use ARIA for team analytics.
Headcount report shows 0
No employees with ACTIVE assignment_status
→ Check /persons — all employees must have ACTIVE worker_assignments. PENDING_HIRE employees are excluded from headcount.
Report loads but no data in date range
Selected date range has no records
→ Expected behaviour — no error. Widen the date range or remove filters. Check if records exist at /persons for the period.
📅 Leave & Payroll Reports
Leave utilisation shows incorrect %
Leave type rules not correctly configured (M2)
→ /master-data/leave-rules → verify each leave type has correct annual_entitlement. Incorrect entitlements affect % calculations.
Payroll report empty
No payroll run with PAID status
→ Run payroll first. At least one run must reach PAID status before payroll reports render any data.
EOSB figure looks wrong
Cross-entity transfer — service reset date may apply
→ Check worker_assignments for any cross-entity transfers. EOSB resets at cross-entity transfer date unless carry-forward agreement exists.
📊 Custom Builder Issues
Report times out or is very slow
Too many fields + no filters = large DB join
→ Add department or entity filter to reduce rows. Salary fields are expensive — only include if needed. Schedule large reports to run off-peak.
Cannot save report as template
Template name already exists
→ Use a unique name. Check /reports/templates for existing saved reports — rename or overwrite the existing one.
Arabic names not showing correctly in CSV
CSV encoding not UTF-8 in Excel
→ When opening CSV in Excel: Data → From Text/CSV → set encoding to UTF-8. AVANIIS exports are always UTF-8 encoded.
⏱ Scheduled Report Issues
Scheduled report not sent
SMTP misconfiguration or recipient email invalid
→ /reports/history → check status. If FAILED → check /settings/notifications → SMTP. Test SMTP connection before retry.
Report was sent but contains old data
Report snapshot time — cron runs at configured time
→ Expected. Scheduled reports are snapshots at the trigger time. For real-time data, run manually at /reports.
Cannot delete a scheduled report
SUPER_ADMIN only can delete scheduled jobs
→ /reports/scheduled → find the job → Actions → Delete. Requires SUPER_ADMIN role. HR_ADMIN can only pause/resume.
Section 10
ARIA Analytics Intelligence
What HR Admins and managers can ask ARIA to generate instant analytics without building a manual report.
ARIAReporting & Analytics — Query Reference
"What is our current headcount by department?"
ARIA checks in order
1.Role = HR_ADMIN → all departments in scope
2.worker_assignments WHERE status=ACTIVE → GROUP BY department_id
3.Return ranked list with totals
"Current headcount: IT 42 · Finance 28 · Operations 35 · HR 12 · Legal 8 · Other 23. Total: 148 active employees. 12 positions currently vacant."
worker_assignments · departments · status=ACTIVE · HR_ADMIN scope
"Which department has the highest leave utilisation?"
ARIA checks in order
1.absence_requests WHERE status in [APPROVED,COMPLETED] YTD
2.Calculate % used against entitlement per department
3.Sort DESC → surface top and bottom performers
"Operations has the highest leave utilisation at 78% YTD. Finance is lowest at 41%. Team-wide average: 63%. Operations team may benefit from staggered leave planning to avoid coverage gaps in Q3."
absence_requests · absence_balances · dept breakdown · YTD
"How many employees are up for promotion review this quarter?"
ARIA checks in order
1.worker_assignments WHERE time_in_current_grade ≥ 12 months
2.Exclude those with open disciplinary records
3.Check no pending promotion already in workflow
"14 employees meet the minimum tenure criterion for promotion review this quarter. Of these, 3 have active promotion requests already in workflow. 11 could be nominated. Would you like the full list?"
worker_assignments · time_in_grade · promotion pipeline
"Show me the EOSB liability for all Finance department employees"
ARIA checks in order
1.Role = HR_ADMIN → salary data accessible
2.persons WHERE dept=Finance → calculate EOSB per FDL 33/2021
3.Sum individual EOSB → total liability
"Finance department total EOSB liability: AED 2,847,000 across 28 employees. Highest individual: Sara Al-Zaabi (14.5 years service). For the full breakdown, go to /reports → Payroll → EOSB Liability."
HR_ADMIN scope · payroll · EOSB · FDL 33/2021
"What is the average time to fill open positions?"
ARIA checks in order
1.positions WHERE vacancy=true → check created_at
2.positions WHERE recently filled → calculate days from vacant to filled
3.Return average and worst/best performers
"Average time to fill: 37 days across the last 12 months. Fastest: Operations (18 days avg). Slowest: Legal (68 days avg). 12 positions currently open — oldest has been vacant for 94 days."
positions · vacancy · created_at · department comparison
"Which managers have the most SLA breaches this month?"
ARIA checks in order
1.workflow_instances WHERE SLA_breached=true AND month=current
2.Group by assigned_to (manager) → COUNT breaches
"Top SLA breaches this month: Khalid Al-Mansoori (IT) — 4 breaches, Mohammed Al-Rashidi (Ops) — 2 breaches. These managers have pending items in /approvals. Would you like to send a reminder?"
workflow_instances · SLA_breached · manager scope
"Compare this month's headcount to last month"
ARIA checks in order
1.Snapshot headcount at start of this month vs last month
2.Calculate net change: hires − exits
3.Break down by type: new hires, terminations, transfers
"This month vs last: net +3. New hires: 5 (IT: 2, Finance: 1, Ops: 2). Exits: 2 (both voluntary resignation). One cross-entity transfer from AVANIIS to Avaniis Construction. Current total: 148."
persons · hire_date · termination_date · MoM comparison
"How many acting assignments are over 5 months?"
ARIA checks in order
1.worker_assignments WHERE is_acting=true AND acting_start_date < today-150days
2.Check each against 6-month UAE Labour Law threshold
"2 acting assignments are over 5 months old. ⚠ Khalid Al-Mansoori (Finance Manager) has been acting for 5 months 20 days — UAE Labour Law requires substantive appointment within 6 months (BR-AC-001). Recommend initiating promotion workflow."
worker_assignments · is_acting · BR-AC-001 · UAE Labour Law

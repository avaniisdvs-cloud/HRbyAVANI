Section 1
Module Overview & Preconditions
Employee Self-Service (ESS) gives every ACTIVE employee direct access to their HR data via /me/* routes — leave, payslips, letters, timesheets, and ARIA. Access provisions automatically when assignment_status becomes ACTIVE.
✅ Preconditions Checklist
✓
Employee has ACTIVE assignment
Configure: /persons/[id] → Assignments
✓
Microsoft Entra ID SSO provisioned
Configure: /users → SSO tab
✓
Leave rules configured (M2 prerequisite)
Configure: /master-data/leave-rules
✓
Payroll module live — M3 prerequisite
Required for payslip visibility at /me/payslips
✓
Letter templates configured — M6 prerequisite
Configure: /employee-letters → Templates
✓
Timesheet rules configured
Configure: /master-data/timesheet-rules
✓
ARIA enabled for employee chat
Configure: /settings/aria → Active ON
🚫 Blocking Conditions
PENDING_HIRE statusESS access denied entirely — activate assignment first.
TERMINATED statusReduced to read-only payslips and letters for 30 days only.
SSO not provisionedEmployee cannot log in — check Entra ID group in /users.
No PAID payroll run/me/payslips shows empty until at least one run is PAID.

Section 9
Troubleshooting
Common ESS issues — problem, root cause, and exact fix.
🚫 Cannot Access /me/* Pages
"Access denied" on any /me/ page
assignment_status is not ACTIVE
→ HR Admin: /persons/[id] → Assignments → set to ACTIVE if hire is confirmed.
Page loads but shows no data
SSO provisioned but EMPLOYEE role not assigned
→ SUPER_ADMIN: /users → find user → assign EMPLOYEE role.
Login redirects to error page
Microsoft Entra ID token expired or SSO misconfigured
→ Clear browser cache and retry. If persistent, IT checks Entra ID group membership.
⏳ Leave Request Issues
Submit button greyed out
Zero balance / dates in past / overlapping leave
→ Check balance on the form. Select future dates. Check for conflicting approved requests.
Approved but balance not deducted
Race condition with accrual cron
→ HR Admin: /absence → [employee] → Recalculate Balance. Correct deduction applies immediately.
Manager not receiving email
SMTP config / manager email missing / spam
→ Check notification_log for FAILED. Verify manager email at /persons/[manager_id].
📄 Payslip & Timesheet Issues
Payslip shows wrong salary
Transfer/promotion was mid-month — pro-rata applies
→ Expected behaviour. Pro-rated payslip is correct. Full new salary from next month.
Cannot edit submitted timesheet
Status PENDING_APPROVAL — locked for editing
→ Ask manager to reject it. Rejected timesheet returns to DRAFT — editable again.
Payslips list is empty
No payroll run with PAID status for this entity
→ Payroll must complete at least one full cycle. Check /payroll for run status.
🤖 ARIA Chat Issues
ARIA not appearing at /me/aria
ARIA Active toggle is OFF
→ SUPER_ADMIN: Settings → AI & Access → AI Agent (ARIA) → Identity → toggle Active ON.
ARIA says "I cannot help with that"
Employee asking about another employee's data — correct behaviour
→ Expected. /me/aria is scoped to own data only. This is PII governance — not a bug.
Voice input not working
Browser does not support Web Speech API
→ Use Chrome or Edge only. Firefox and Safari do not support Web Speech API.
Section 10
ARIA Intelligence — ESS Queries
What employees and HR admins can ask ARIA about the self-service portal. Employee ARIA (/me/aria) is scoped to own data only.
ARIAEmployee Self-Service — Query Reference
"How many leave days do I have left?"
ARIA checks in order
1.Identify user from session → persons.id
2.absence_balances WHERE person_id = user AND leave_type = ANNUAL
3.Check next accrual date from leave_rules
"You have 14 days of annual leave remaining. Your next accrual of 2.5 days is on 1 June 2026."
absence_balances · leave_rules · BR-LV-001
"When was my last payslip?"
ARIA checks in order
1.Find most recent payroll_run WHERE status=PAID AND employee included
2.Return period and net pay from salary_elements
"Your last payslip was April 2026, paid on 30 April. Net pay: AED 19,850. View it at /me/payslips."
payroll_runs · salary_elements · status=PAID
"Can you show me Ahmed's salary?" (from another employee)
ARIA checks in order
1.Requesting user role = EMPLOYEE
2.Target ≠ requesting user → ACCESS DENIED at governance layer
"I'm not able to share another employee's salary. This is restricted to HR Admins and above. For your own salary, check /me/payslips."
Role permissions · PII governance · /me/* scope
"How do I apply for 3 days leave next week?"
ARIA checks in order
1.Check annual leave balance ≥ 3
2.Check no overlapping approved requests
3.Authority level → Advisory = guide to form
"You have 14 days available and no conflicts. Go to My Leave → New Request, select Annual Leave, pick your dates, and submit. Your manager will be notified immediately."
absence_balances · absence_requests · /me/leave
"Who is my line manager?"
ARIA checks in order
1.worker_assignments WHERE person_id = user → line_manager_id
2.persons WHERE id = line_manager_id → name_en, name_ar
"Your line manager is Sara Al-Zaabi (سارة الزعبي), Head of IT Operations."
worker_assignments.line_manager_id · persons
"My payslip looks wrong this month"
ARIA checks in order
1.Check if transfer/promotion effective_date was mid-month → pro-rata expected
2.Check for acting allowance additions/removals
3.If genuinely wrong → escalate to HR Admin
"A transfer was effective on the 15th, so your payslip is pro-rated — that is correct. If the amounts still seem wrong, I'll connect you with your HR Admin."
salary_elements · effective_date · worker_assignments
"What documents do I need to sign?"
ARIA checks in order
1.employee_letters WHERE person_id = user AND status = SENT
2.Check token expiry dates — flag urgent ones
"You have 1 letter pending signature: Promotion Letter (sent 18 May 2026, expires 17 June 2026). Check My Letters or use the link in your email."
employee_letters.status=SENT · token expiry · /me/letters
"How do I download all my personal data?"
ARIA checks in order
1.Confirm DSAR is from the data subject themselves
2.Guide to /me/profile → Download My Data
"Go to My Profile (/me/profile) and click Download My Data (DSAR). A ZIP with all your HR data downloads immediately. The link expires in 24 hours."
DSAR · persons · /me/profile · UAE Data Protection

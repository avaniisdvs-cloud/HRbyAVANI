Operational Scenarios
Four real-world letter scenarios with step-by-step resolution.
A
Salary certificate shows wrong amount
1
Employee reports salary figure on certificate is wrong
2
HR Admin: check which payroll run was selected during generation
3
If a CALCULATED run was selected, salary may be a draft figure — not final
4
Recall the letter: /employee-letters → Actions → Recall (only if not yet signed)
5
Regenerate selecting the correct PAID run → resend to employee
employee_letters · payroll_runs.status=PAID · recall action
B
Employee signing link expired
1
Employee clicks link — "This link has expired or already been used"
2
HR Admin: /employee-letters → find letter → status = SENT (not SIGNED)
3
Click Actions → Resend Link — new JWT token, 30-day clock resets
4
New email sent to employee. Original token permanently invalidated.
⚠ Resending creates a completely new token. The old email link cannot be reactivated once a new one is issued.
JWT expiry · 30 days · Resend action · /employee-letters
C
Warning letter issued without HR Director approval
1
HR Admin attempts to generate warning letter — system prompts for HR Director approval
2
HR Director receives approval request in /approvals inbox
3
HR Director reviews incident details and approves or rejects
4
On approval — HR Admin can now generate and send the warning letter
⚠ UAE Labour Law (FDL 33/2021 Art. 40): disciplinary letters require documented approval chain. Letters without approval may invalidate the disciplinary process legally.
FDL 33/2021 Art.40 · HR Director approval · BR-29
D
Promotion letter generated before effective date
1
HR Admin generates promotion letter — {{new_salary}} shows blank
2
Root cause: promotion approved but effective_date has not arrived yet — not EXECUTED
3
Recall the letter (status must be SENT, not SIGNED)
4
Wait for effective_date to pass — system executes promotion and updates salary_elements
5
Regenerate promotion letter — {{new_salary}} now populates correctly

Section 9
Troubleshooting
Common letter module issues — problem, root cause, and exact fix.
🚫 Generation Fails
PDF not generating — merge error shown
Template uses {{salary}} but no PAID payroll run exists
→ Use a template that doesn't need salary, or wait until payroll run reaches PAID status.
DOMPurify blocking content
Template body contains HTML tags or script elements
→ Use plain text only in templates. HTML is stripped by DOMPurify. Formatting is controlled by the template structure.
{{new_salary}} shows blank
Promotion approved but effective_date not yet reached
→ Wait for effective_date. System auto-executes. Then regenerate the letter.
📧 Delivery Issues
Employee not receiving the email
No email on file / SMTP misconfigured / spam filter
→ Check notification_log for FAILED status. Verify email at /persons/[id]. Check SMTP at /settings/notifications.
Email received but link is broken
Token already consumed or letter was recalled
→ Check letter status in /employee-letters. If RECALLED, regenerate. If SIGNED, no action needed.
Employee cannot open /letters/sign/[token]
URL was modified or copied incorrectly
→ Resend the link fresh from /employee-letters. Confirm employee opens the latest email.
📋 Status Issues
Letter stuck in SENT — employee says they signed
Browser closed / network dropped before confirmation completed
→ Check audit_log for signature event. If none found, resend — the token is still valid if not consumed.
Recall button not showing
Letter is already SIGNED — recall only possible before signing
→ If content was wrong and already signed, generate a corrected letter and note original is superseded.
Letter has no status badge
Letter is DRAFT — not yet generated or sent
→ /employee-letters → find draft → click Send to generate PDF and send JWT link.
🤖 ARIA Letter Help
ARIA says it cannot generate letters
ARIA at Advisory level guides, does not execute
→ Expected. HR Admin generates letters at /employee-letters. ARIA provides status and guidance only.
Employee asks ARIA for a salary certificate
ARIA cannot generate documents — only check existing ones
→ ARIA checks /me/letters for existing certificates and guides employee to contact HR Admin if none found.
ARIA cannot check unsigned letter count
Letters data source not enabled in Behaviour tab
→ SUPER_ADMIN: Settings → AI & Access → Behaviour → enable Letters data source.
